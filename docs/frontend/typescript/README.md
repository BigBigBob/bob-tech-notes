# TypeScript

TypeScript 专题收录语言入门、静态类型系统、模块、编译配置及官方 Handbook 学习笔记。

## 文章列表

- [TypeScript 基础知识](./TypeScript基础知识.md)：根据官方入门教程和 Handbook 整理，涵盖类型推断、接口、联合类型、泛型、结构类型系统、JavaScript 模块、编译工具、严格检查及常用类型。

## 内容导览

当前笔记包含以下七部分，均收录在《TypeScript 基础知识》中：

1. 面向 JavaScript 程序员的 TypeScript 入门：类型推断、接口、联合类型、类型收窄和泛型。
2. 面向 Java/C# 程序员的类型系统：类、结构类型、类型擦除及运行时判断。
3. JavaScript 模块：命名空间、私有作用域、模块加载以及导入和导出。
4. 五分钟了解 TypeScript：安装、编译、类型注解和浏览器示例。
5. Handbook 导言：静态检查的用途、手册结构和学习入口。
6. The Basics：编译器、类型推断、类型擦除、降级编译和严格模式。
7. Everyday Types：基本类型、函数与对象、联合类型、类型别名、接口、断言和字面量类型。

## 阅读建议

先掌握 [JavaScript 基础知识](../javascript/JavaScript基础知识.md)，再阅读 TypeScript 入门和编译示例，随后学习 Handbook 的 The Basics 与 Everyday Types。具有 Java/C# 背景的读者可结合第二部分理解结构类型系统。
