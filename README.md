# Bob Tech Notes

一个持续整理的中文技术知识库，用于沉淀学习笔记、实践记录和专题文章。内容以可查阅、可复现为目标，在记录常用操作的同时，也会说明命令背后的原理、适用场景和风险边界。

## 使用说明

仓库中的文档均使用 Markdown 编写，可以直接在线阅读，也可以下载后通过任意 Markdown 编辑器查看。



## 参与完善

如果你发现内容错误、示例过时或有值得补充的实践经验，欢迎提交 Issue 或 Pull Request。新增文档时，建议按照 `docs/<技术方向>/<专题>/` 的结构归档，并在本 README 的文档导航中补充入口。
