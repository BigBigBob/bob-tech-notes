# TypeScript

TypeScript 專題收錄語言入門、靜態型別系統、模組、編譯配置及官方 Handbook 學習筆記。

## 文章列表

- [TypeScript 基礎知識](./basics.md)：根據官方入門教程和 Handbook 整理，涵蓋型別推斷、介面、聯合型別、泛型、結構型別系統、JavaScript 模組、編譯工具、嚴格檢查及常用型別。

## 內容導覽

當前筆記包含以下七部分，均收錄在《TypeScript 基礎知識》中：

1. 面向 JavaScript 程式設計師的 TypeScript 入門：型別推斷、介面、聯合型別、型別縮小和泛型。
2. 面向 Java/C# 程式設計師的型別系統：類、結構型別、型別擦除及執行階段判斷。
3. JavaScript 模組：名稱空間、私有作用域、模組載入以及匯入和匯出。
4. 五分鐘瞭解 TypeScript：安裝、編譯、型別註解和瀏覽器範例。
5. Handbook 導言：靜態檢查的用途、手冊結構和學習入口。
6. The Basics：編譯器、型別推斷、型別擦除、降級編譯和嚴格模式。
7. Everyday Types：基本型別、函式與物件、聯合型別、型別別名、介面、斷言和字面量型別。

## 閱讀建議

先掌握 [JavaScript 基礎知識](../javascript/basics.md)，再閱讀 TypeScript 入門和編譯範例，隨後學習 Handbook 的 The Basics 與 Everyday Types。具有 Java/C# 背景的讀者可結合第二部分理解結構型別系統。
