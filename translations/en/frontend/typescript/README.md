# TypeScript

This topic covers the language, static typing, modules, compiler configuration, and the official TypeScript Handbook.

## Articles

- [TypeScript Fundamentals](./basics.md) draws on the official tutorials and Handbook. It covers type inference, interfaces, union types, generics, structural typing, JavaScript modules, compiler tooling, strict checking, and everyday types.

## What the article covers

1. TypeScript for JavaScript Programmers — type inference, interfaces, union types, narrowing, and generics.
2. TypeScript for Java/C# Programmers — classes, structural typing, type erasure, and runtime checks.
3. JavaScript modules — namespaces, private scope, module loading, imports, and exports.
4. TypeScript in 5 Minutes — installation, compilation, type annotations, and a browser example.
5. The TypeScript Handbook — what static checking is for, how the Handbook is organized, and where to start.
6. The Basics — the compiler, type inference, type erasure, downlevel compilation, and strict mode.
7. Everyday Types — basic types, functions and objects, unions, type aliases, interfaces, assertions, and literals.

## Suggested reading

Start with [JavaScript Fundamentals](../javascript/basics.md), then work through the TypeScript introduction and compiler examples. After that, read The Basics and Everyday Types in the Handbook. If you come from Java or C#, the second section can help you understand structural typing.
